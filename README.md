# Хайфский семейный квиз

Многопользовательский квиз: ведущий показывает вопросы на большом экране, игроки отвечают с телефонов.

## Как играть

1. Ведущий открывает сайт и нажимает **«Создать комнату»** — появляется код комнаты, ссылка и QR-код.
2. Игроки сканируют QR (или открывают сайт и вводят код), вводят имя и попадают в лобби.
3. Ведущий нажимает **«Начать игру»**. 12 вопросов по 30 секунд: правильный ответ — 500 очков + до 500 за скорость.
   Ответ открывается автоматически, когда ответили все или вышло время.

Если игрок или ведущий перезагрузит страницу — игра продолжится: игрок переподключится с теми же очками,
ведущий может нажать «Вернуться в комнату».

## Как это устроено

- Чистый статический сайт (`index.html`, `css/`, `js/`) — подходит для GitHub Pages, сервер не нужен.
- Связь — через публичный MQTT-брокер по WebSocket (`wss://broker.emqx.io:8084/mqtt`). Прямых соединений
  между устройствами нет, поэтому игра работает в любой сети, где открываются сайты: Wi-Fi, мобильный
  интернет, игроки в разных сетях.
- Браузер ведущего хранит всё состояние игры (фаза, вопрос, игроки, ответы, очки) и рассылает его игрокам;
  игроки отправляют только имя и ответы. Комната — это код из 5 символов.
- Вопросы лежат в `js/questions.js`, сторонние библиотеки — в `js/vendor/` (без зависимости от CDN).

### Свой брокер

Добавьте к адресу параметр `?broker=wss://host:port/path` — он автоматически попадёт и в ссылку для игроков.

### Локальный запуск

```sh
python3 -m http.server 8080
# открыть http://localhost:8080
```
