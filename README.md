# Семейный квиз: Хайфа, Вена и Днепр

Многопользовательский квиз: ведущий показывает вопросы на большом экране, игроки отвечают с телефонов.

## Как играть

1. Ведущий открывает сайт и нажимает **«Создать комнату»** — появляется код комнаты, ссылка и QR-код.
   В лобби ведущий выбирает квиз: **Хайфа** (суржик-иврит), **Вена** (суржик-дойч) или **Днепр** (днепровский суржик).
2. Игроки сканируют QR (или открывают сайт и вводят код), вводят имя и попадают в лобби.
3. Ведущий нажимает **«Начать игру»**. 12 вопросов по 30 секунд. Очки зависят от скорости: правильный ответ сразу — 1000,
   в последнюю секунду — около 100 (100 за правильность + до 900 за скорость, линейно по времени).
   Ответ открывается автоматически, когда ответили все или вышло время.
   Кто угадал — получает конфетти на телефоне; итоговое окно тоже с конфетти.

Если игрок или ведущий перезагрузит страницу — игра продолжится: игрок переподключится с теми же очками,
ведущий может нажать «Вернуться в комнату».

## Как это устроено

- Чистый статический сайт (`index.html`, `css/`, `js/`) — подходит для GitHub Pages, сервер не нужен.
- Связь — через публичный MQTT-брокер по WebSocket (`wss://broker.emqx.io:8084/mqtt`). Прямых соединений
  между устройствами нет, поэтому игра работает в любой сети, где открываются сайты: Wi-Fi, мобильный
  интернет, игроки в разных сетях.
- Браузер ведущего хранит всё состояние игры (фаза, вопрос, игроки, ответы, очки) и рассылает его игрокам;
  игроки отправляют только имя и ответы. Комната — это код из 5 символов.
- Код (`js/app.js`) отделён от текста: все надписи и вопросы лежат в JSON-файлах в папке `data/`.
  Сторонние библиотеки — в `js/vendor/` (без зависимости от CDN).

## Где менять тексты

| Файл | Что внутри |
|---|---|
| `data/texts.json` | Все надписи интерфейса: кнопки, статусы, подсказки. `{name}`, `{code}` и т. п. подставляются игрой — их не трогайте. |
| `data/quizzes/index.json` | Список квизов (`quizzes`) и квиз по умолчанию (`default`). |
| `data/quizzes/<id>.json` | Один квиз: оформление и вопросы. |

Поля квиза: `name` (на переключателе), `brand` (в шапке), `title` (заголовок, можно `<em>`), `eyebrow`,
`round2` (подпись второй половины), `finale`, `empty` (если никто не ответил), `placeholder` (пример имени) и `questions`.

Вопрос:

```json
{
  "question": "Текст вопроса",
  "options": ["А", "Б", "В", "Г"],
  "answer": 2,
  "explanation": "Пояснение для ведущего"
}
```

`answer` — номер правильного варианта **с нуля**: 0 = А, 1 = Б, 2 = В, 3 = Г. Вариантов всегда 4.
Неправильно оформленный вопрос игра пропустит и напишет об этом в консоли браузера.

Новый квиз: создайте `data/quizzes/<id>.json` и допишите `<id>` в `data/quizzes/index.json`.
После правки файлов увеличьте `VERSION` в `js/app.js` и `?v=` в `index.html`, чтобы браузеры не взяли старые файлы из кеша.

### Свой брокер

Добавьте к адресу параметр `?broker=wss://host:port/path` — он автоматически попадёт и в ссылку для игроков.

### Локальный запуск

```sh
python3 -m http.server 8080
# открыть http://localhost:8080
```

Игра загружает JSON-файлы, поэтому её нужно открывать через веб-сервер (как выше или на GitHub Pages),
а не двойным кликом по `index.html`.
